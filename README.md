# Healthy Skepticism — Course SiteSource for healthy-skepticism.com, served by GitHub Pages.## Structure- `index.html` — the entire site (single page)- `CNAME` — custom domain for GitHub Pages- `papers/` — public whitepaper PDFs, linked from the Course Papers section## Updating the siteEdit `index.html` and commit; GitHub Pages redeploys automatically withina minute or two. To add a paper: drop the PDF into `papers/` and add a lineto the paper list in `index.html`.Participant-only materials live in a shared Google Drive folder. The siteholds only the link, revealed behind the passphrase gate. The passphraseand Drive link are set at the top of the script block in `index.html`.Note the gate is a courtesy screen, not security: anyone reading the pagesource can find the link, so nothing sensitive should go in that folder.
